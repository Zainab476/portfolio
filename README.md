# Portfolio Page

This project is a personal portfolio page created using HTML and vanilla CSS.
The goal of this assignment is to practice CSS layout techniques, especially
Flexbox, while building a professional-looking website.

## Features
- Responsive layout using Flexbox
- Clean and modern UI
- Sections for About, Skills, Projects, and Contact

## Technologies Used
- HTML5
- CSS3 (Flexbox)

Design inspired by modern portfolio layouts.
