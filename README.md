# 💼 Personal Developer Portfolio Page

A personal portfolio website built to showcase my software engineering projects, technical skills, background, and professional journey. This repository was created as part of **Assignment 2: Portfolio Page**.

---

## ✨ Features

* **About Me Section:** Overview of my background, technical journey, and core software engineering interests.
* **Featured Projects Showcase:** Highlighted breakdown of key projects, including tech stacks, core features, and GitHub/live demo links.
* **Technical Skills Grid:** Structured display of programming languages, frameworks, backend/frontend tools, and databases.
* **Interactive UI & Smooth Navigation:** Intuitive navigation bar for quick jumping between sections (About, Projects, Skills, Contact).
* **Contact & Links:** Direct links to my professional profiles (GitHub, LinkedIn, Email).

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Layout & Styling:** Custom CSS Flexbox / Grid, CSS Variables for thematic consistency, and responsive media queries.
