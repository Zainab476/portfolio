Predicting Traffic Accident Severity in Bahrain – Comparative Study of Classification Methods

Description

A machine learning project analyzing 35,999 traffic accident records in Bahrain to predict severity levels (Fatal, Serious, Slight). Evaluated multiple classification models and addressed challenges like class imbalance and feature engineering.

Technologies Used

R, Multinomial Logistic Regression, LDA, QDA, KNN, SMOTE, Random Forest
